# memo

日々の作業メモ・会議メモのための、**HTML 1 ファイル**で完結する軽量テキストエディタ。

ビルド不要・依存パッケージなし・インストール不要。ブラウザで開くだけで使えます。
開いたファイルへ `Ctrl+S` でそのまま上書き保存できます。

👉 **[https://georgemandokoro.github.io/memo/](https://georgemandokoro.github.io/memo/)**

---

## 特長

- **`.txt` / `.md` の読み書き** — File System Access API により、開いたファイルへ直接上書き保存
- **アウトライン** — Markdown 見出しを自動抽出してサイドバーに表示。クリックでジャンプ
- **TODO 一覧** — 文書中の未完了タスクを集めて見出しごとに一覧表示
- **プレビュー** — Markdown を HTML に変換して並べて表示（スクロール同期あり）
- **検索・置換** — 全ヒットをハイライト、正規表現対応
- **自動保存** — 入力が止まって 3 秒後に静かに上書き（ダイアログは出ません）
- **文字コード / 改行コードの自動判別** — UTF-8 / Shift_JIS、CRLF / LF / CR を判別し、改行コードは元のまま保存
- ダーク / ライトテーマ、サイドバー幅変更、未保存内容の自動退避

## 使い方

1. 上のリンクを開く
2. `Ctrl+O` でファイルを開く（またはウィンドウにドラッグ＆ドロップ）
3. 書く。`Ctrl+S` で保存（自動保存が有効なら放っておいても保存されます）

ローカルに置いて使う場合は `index.html` をダウンロードし、ダブルクリックで開いてください。
`file://` でも同じように動作します。

## アプリとしてインストールする（PWA）

https で配信されている場合のみ、Chrome / Edge の「インストール」からアプリとして導入できます。

- **独立したウィンドウ**で起動（タブもアドレスバーも無し）
- **エクスプローラーから `.md` / `.txt` をダブルクリック**すると、このエディタで開きます（書き込み権限つき）
- **起動時に前回のファイルを自動で開きます**。インストール済みアプリではファイルへの許可が保持されるため、
  確認ダイアログは出ません（許可が切れている場合のみ、上部に「前回のファイル ［開く］」が出ます）
- Service Worker により**オフラインでも起動**します

`file://` で直接開いた場合、これらの機能は使えません（通常のエディタとしては同じように動作します）。

## 対応ブラウザ

| ブラウザ | 状態 |
|---|---|
| Chrome / Edge | ✅ すべての機能が動作（ファイルへの直接上書き保存を含む） |
| Firefox / Safari | ⚠️ 閲覧・編集は可能。保存はダウンロード形式になります |

ファイルへの直接上書き保存は [File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_API) に依存しています。

## 補足

- 保存時の文字コードは **UTF-8**。Shift_JIS のファイルを開いた場合、保存すると UTF-8 に変換されます（ステータスバーに判別結果を表示）
- 改行コードは読み込み時のものを維持します（CRLF / LF / CR）
- 未保存の内容はブラウザ内に自動退避され、次回起動時に復元できます
- 設定（テーマ・文字サイズ・サイドバー幅など）はブラウザの localStorage に保存されます

## 開発

`index.html` の 1 ファイルのみで、ビルド手順はありません。編集してブラウザで再読み込みするだけです。
